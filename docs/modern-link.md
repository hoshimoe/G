# Modern Link 友情链接页面

`link_modern.php` 是友情链接页面的「现代」模板。它会读取 **Links 插件** 的友链数据，
渲染为玻璃拟态（frosted glass）卡片网格，并支持按分类分组、随机排序等显示方式。

要使用此模板，请在 Typecho 后台新建一个独立页面，并将其「自定义模板」设为
**友情链接 - 现代 / link_modern.php**。页面正文会显示在顶部 Hero 区域，可用于写
申请友链的说明、规则等内容。

## 自定义排序与分类

卡片的分组依据来自 Links 插件每条友链的 **「sort（分类 / 排序）」** 字段。该字段
有几种特殊写法：

### 1. 普通分类

直接填写分类名称即可，例如 `好友`、`技术博客`。相同 sort 值的友链会在「按分类」
显示方式下归入同一分组，分组标题即为该名称。

留空的友链会被归入「未分类」分组。

### 2. 带优先级的分类

使用 `数字|名称` 的格式可以控制分组的显示顺序，数字越小越靠前。例如：

| sort 字段值 | 显示标题 | 优先级 |
| ----------- | -------- | ------ |
| `1\|好友`   | 好友     | 1      |
| `2\|同学`   | 同学     | 2      |
| `好友`      | 好友     | 无（排在带数字的之后） |

未带数字的分类会排在所有带数字的分类之后。

### 3. 失联星球（自动灰显）

当 sort 字段匹配到「失联 / 失聯 / lost / offline / broken / 下线 / 下線 / dead」等
关键词时，该友链会被收进 **「失聯星球」** 分组，卡片自动灰显，鼠标悬停时恢复彩色。

### 4. 待办星球

当 sort 字段匹配到「待办 / 待辦 / todo / pending / 问题 / 問題」等关键词时，该友链
会被收进 **「待辦星球」** 分组。

## 显示方式

「顯示方式」下拉框（页面右上角）是否出现，取决于后台设置：

- 当后台设为 **均顯示** 时，下拉框会显示，访客可在以下几种方式间切换，选择会记录在
  浏览器 `localStorage` 中。
- 当后台固定为某一种方式时，下拉框会被隐藏，页面只按该方式显示。

可选的显示方式：

- **平鋪**：按友链原始顺序平铺展示（失联 / 待办分组仍排在末尾）。
- **按分類**：按上文的分类 / 优先级规则分组展示（仅当存在分类时可选）。
- **隨機**：每次加载都把友链随机打乱展示。

## 鼠标悬停提示

卡片的原生悬停提示（`title`）显示的是友链的 **描述（description）** 文本，而非名称。

## 后台主题设置

在主题设置的 **Modern Link** 分组中可以配置默认行为：

- **Modern Link 列數**：卡片网格的列数（1〜6）。留空则按视窗宽度自适应排列。
- **Modern Link 顯示方式**：控制页面的显示方式。
  - **均顯示**：页面右上角显示「顯示方式」下拉框，访客可自行在平铺 / 按分类 / 随机
    之间切换，选择会记录在浏览器中（默认值）。
  - **平鋪 / 按分類 / 隨機**：固定为该方式显示，前端不再显示切换下拉框。
