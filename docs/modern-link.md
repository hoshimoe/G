# Modern Link 友情链接页面

`link_modern.php` 是友情链接页面的「现代」模板。它读取友链插件的数据，渲染为
可搜索、可切换显示方式的卡片列表，并支持置顶、分类、待办与失联分组。

要使用此模板，请在 Typecho 后台新建一个独立页面，并将其「自定义模板」设为
**友情链接 - 现代 / link_modern.php**。页面正文用于写申请友链的说明、本站信息等，
默认显示在友链列表上方（可在主题设置中改为下方）。

## 数据来源

- 启用 **Links** 插件（经典友链插件）时读取它的数据。模板经由插件公开的 `output()`
  读取，插件自己的显示状态、排序与默认图片规则仍然生效。
- 未启用 Links、但启用了 **NekoTypechoLinks** 时，改读它的友链，`category` 字段对应
  下文的 sort（分类）。
- 两者都未启用时，页面显示提示。

卡片会显示头像、名称、描述与网址的域名。没有头像、或头像加载失败时，显示名称首字
的字母头像。

## 分类、置顶与特殊分组

卡片的分组依据来自每条友链的 **sort（分类）** 字段（NekoTypechoLinks 为 category）。

### 1. 普通分类

直接填写分类名称即可，例如 `好友`、`技术博客`。相同 sort 值的友链会在「分类」
显示方式下归入同一分组，分组标题即为该名称。留空的友链归入「未分类」。

### 2. 带优先级的分类

使用 `数字|名称` 的格式控制分组顺序，数字越小越靠前：

| sort 字段值 | 显示标题 | 优先级 |
| ----------- | -------- | ------ |
| `1\|好友`   | 好友     | 1      |
| `2\|同学`   | 同学     | 2      |
| `好友`      | 好友     | 无（排在带数字的之后） |

### 3. 置顶

sort 字段**整个值**为 `pin`、`pinned`、`sticky`、`top`、`featured`、`置顶`、`置頂`、
`精选`、`精選`（可带 `数字|` 前缀）时，该友链进入最上方的 **「置頂」** 分组。
置顶分组在任何显示方式下都排在最前，随机显示时也不打乱。

### 4. 待办星球

sort 字段包含「待办 / 待辦 / todo / pending / 问题 / 問題」等关键词时，该友链收进
**「待辦星球」** 分组，排在列表末尾。

### 5. 失联星球（自动灰显）

sort 字段包含「失联 / 失聯 / lost / offline / broken / 下线 / 下線 / dead」等关键词时，
该友链收进 **「失聯星球」** 分组，排在最后；卡片灰显，鼠标悬停时恢复。

## 搜索

列表上方的搜索框按名称、描述、域名与分类名筛选，不分大小写与简繁；多个关键词以
空格分隔时须全部符合。按 `/` 聚焦搜索框，`Esc` 清除。

## 显示方式

- **平铺**：按友链原始顺序展示（置顶在前，待办 / 失联在后）。
- **分类**：按上文的分类 / 优先级规则分组展示（仅当存在分类时可选）。
- **随机**：打乱一般友链的顺序；再次点击会重新洗牌。

切换时卡片以动画移动到新位置（系统设置「减少动态效果」时关闭）。

后台设为 **均显示** 时，访客可在页面上切换，选择记录在浏览器 `localStorage`
（`modernLinkDisplay`）中；固定为某一种方式时，切换控件隐藏。

## 简繁转换

页面正文与卡片的名称、描述都跟随主题的内容语言选择器（`translate.js`）转换，
选择器显示在页面标题区的右上角。正文的转换规则与文章页相同；卡片文字常由各站点
自己填写、简繁混用，因此选择简体或繁体时一律转换，选择「显示原文」时恢复原样。

`translate.js` 对其他页面同样开放这两个钩子：

- `[data-g-translate]`：标记正文以外需要转换的区块。转换在原节点上进行，不重建 DOM；
  其中带 `translate="no"` 的元素跳过。之后才插入页面的区块，用
  `window.refreshContentTranslation(元素)` 套用当前语言。
- `[data-g-translate-mount]`：语言选择器放进这个元素，而不是文章顶部。

## 其他

- 页面正文里的代码块（例如本站友链信息）右上角有「复制」按钮。
- 卡片的原生悬停提示（`title`）显示友链描述。
- 头像请求不带 Referer（`referrerpolicy="no-referrer"`），减少因防盗链而加载失败的头像。

## 后台主题设置

在主题设置的 **Modern Link** 分组中可以配置：

- **Modern Link 列数**：卡片网格的列数（1〜6）。留空则按宽度自动排列；窄屏一律单列。
- **Modern Link 显示方式**：
  - **均显示**：访客可在平铺 / 分类 / 随机之间切换（默认值）。
  - **平铺 / 按分类 / 随机**：固定为该方式，前端不显示切换控件。
- **Modern Link 正文位置**：页面正文显示在友链列表的上方（默认）或下方。
